# Ecommerce Sales Analysis Power BI Project

## Project Overview

**Project Title**: Ecommerce Sales Analysis  
**Level**: Beginner  
**Tool**: Power BI  

This Power BI project analyzes ecommerce sales performance using an interactive dashboard. The project uses a dataset containing product sales information and demonstrates data transformation, DAX calculations, visualization design, and publishing to Power BI Service. The dashboard was created by following a YouTube tutorial and customized for personal learning and portfolio purposes.

## Objectives

1. **Data Import and Cleaning**: Load the dataset into Power BI and clean it using Power Query Editor.
2. **Data Modeling**: Create a star schema by building relationships between fact and dimension tables.
3. **DAX Measures**: Write DAX formulas to calculate KPIs like Total Sales, Profit, and Profit Margin.
4. **Visualization**: Build an interactive report with filters, charts, KPIs, and tables.
5. **Insight Generation**

## Findings

- **Customer Demographics**: The dataset includes customers from various age groups, with sales distributed across different categories such as Clothing and Beauty.
- **High-Value Transactions**: Several transactions had a total sale amount greater than 1000, indicating premium purchases.
- **Sales Trends**: Monthly analysis shows variations in sales, helping identify peak seasons.
- **Customer Insights**: The analysis identifies the top-spending customers and the most popular product categories.

## Reports

- **Sales Summary**: A detailed report summarizing total sales, customer demographics, and category performance.
- **Trend Analysis**: Insights into sales trends across different months and shifts.
- **Customer Insights**: Reports on top customers and unique customer counts per category.

## Conclusion

This Power BI project showcases the ability to create professional, insightful dashboards for e-commerce businesses. The findings can assist stakeholders in making informed decisions around inventory, marketing, and customer engagement strategies.
